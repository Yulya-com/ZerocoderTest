## [1.0.0] - 2026-10-12

### Added
- Приём сообщений сообщества ВКонтакте через Long Poll.
- Интеграция с GigaChat API: получение токена и генерация ответов.
- Сборка системного промпта и базы знаний (`bot/knowledge.py`).
- База знаний о курсах Zerocoder (`knowledge/zerocoder.md`).
- Системный промпт Алины (`prompts/alina_system_prompt.txt`).
- Конфигурация через `.env` с валидацией обязательных переменных.
- Память диалога с ограничением числа пар «вопрос-ответ».
- Команды `/start` и `/reset`, приветствие по имени пользователя.
- Разбивка длинных ответов под лимит сообщения ВКонтакте.
- Модульные тесты (pytest) для конфигурации и базы знаний.
- CI на GitHub Actions: компиляция и тесты на Python 3.10–3.12.
- Документация: README, `docs/ARCHITECTURE.md`, `docs/GIT-WORKFLOW.md`.
- Лицензия MIT.
